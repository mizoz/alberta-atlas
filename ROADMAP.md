# Alberta Atlas roadmap

Alberta Atlas is a working local application under active development. This public repository currently contains its showcase and contribution hub. These are priorities, not release-date promises.

## Discovery and detailed profiles

- Add real site photos with photographer credit, reuse permission, alt text and clear location context.
- Make profile descriptions easier to scan: landscape, published activities, access wording, restrictions and original source.
- Improve mobile browsing, filters and map inspection.
- Keep the README gallery current as the interface improves.

## Better access evidence

- Find authoritative provincewide land ownership and jurisdiction coverage; the current Crown extract is partial.
- Add agricultural disposition and recreation-access conditions with source dates.
- Reconcile PLUZ maps with route-level vehicle restrictions, seasons and closures.
- Document lawful approaches, entrances, parking and staging areas using authoritative records or documented field work.
- Add road and closure geometry where the evidence supports it.

## Reliability and community

- Measure map performance with larger layers and on mobile devices.
- Make data refreshes reproducible while preserving original geometry and provenance.
- Resolve project licensing and dataset redistribution terms before broader public distribution.
- Assess public hosting after the local browsing and access information are ready.

The project already has searchable conservation records, 2026 pheasant release listings, map overlays, overlapping-feature inspection, comparisons, exports and Calgary access research. See [README.md](README.md) for current coverage and public-release scope.
