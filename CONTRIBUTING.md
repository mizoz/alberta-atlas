# Contributing to Alberta Atlas

Help make Alberta places easier to discover and their access conditions easier to understand. Start with a focused issue describing the place, problem or proposed improvement. For code changes, keep pull requests small and explain how you checked the result.

## Site descriptions and access corrections

Include the site name or record ID, an official source URL, the date you checked it, and the exact fact that needs correction. Distinguish published rules from personal observations. Keep ownership, permission to enter, hunting permission and vehicle access separate. Coordinates must describe what they represent: property geometry, an approximate reference, or a documented entrance.

Do not infer public access from a nearby road, Crown classification or trail line. Wildlife mentions describe source wording, not guaranteed sightings. Preserve original geometry and provenance when updating a dataset.

## Photos

Site photos are welcome as a next step; the README currently shows application screenshots. Submit only photos you took or have permission to redistribute. Include:

- Site name and what the photo shows.
- Capture date, or an explicit statement that the date is unknown.
- Photographer credit and permission/licence terms.
- Location context, including whether a photographed gate or parking area has verified access conditions.
- Useful alt text describing the scene.

Remove private information and precise location metadata when it is unnecessary. Do not upload credentials, faces without permission, vehicle plates or personal notes. A photo of a gate or track alone does not verify legal access. Avoid AI-generated scenery presented as a real place.

## Development status

This public release contains documentation and screenshots. Application source and datasets are not yet distributed here. Use issues for specific feature requests, reproducible observations from an available local copy, and evidence-backed data corrections. Documentation pull requests are welcome.

Do not upload copied site descriptions, third-party map images, restricted datasets or personal information. Dataset and photo redistribution rights must be documented before inclusion.
